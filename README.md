# Wunderreich

**Vanilla+ mechanics for Minecraft (Fabric): shared chests, villager trade control, trowels, item tubes and the slabs,
stairs and walls vanilla forgot.**

**Wunderreich** is a Minecraft mod for [Fabric](https://fabricmc.net/) that adds niceties and new mechanics which feel
like they belong in the vanilla game. Every feature can be switched off in the config or with game rules, so you decide
which parts you use.

## Features

- 🎁 **Wunderkiste** – chests that all share one inventory. Dye them, or rename them, to build separate networks.
- 🤑 **Whisperers** – reroll the trades of an untrained villager; an *Imprinted Whisperer* makes Librarians offer the
  enchanted book you imprinted.
- 🛠️ **Builder's Trowels** – place a random block from your hotbar, perfect for natural-looking patterns. Comes in
  wood, iron and diamond (Master Builder's) variants.
- 🧲 **Suction Tube** – an "upward hopper" with built-in item filters and redstone control.
- 🧱 **Slabs, stairs and walls** – slabs for grass, dirt, dirt paths, coarse dirt, sand, red sand, glass, stained glass,
  concrete, terracotta and wool (sand slabs fall, grass spreads to dirt slabs), plus stairs and walls for wool,
  concrete, terracotta, amethyst, copper and all wood types.
- 🔌 **Integrations** – recipes in [JEI](https://modrinth.com/mod/jei) and [REI](https://modrinth.com/mod/rei),
  [WTHIT](https://modrinth.com/mod/wthit) tooltips, and a config screen through
  [Mod Menu](https://modrinth.com/mod/modmenu).

## Building from source

You need JDK 25 for the 26.x branches (JDK 21 for 1.21.x, JDK 17 for 1.20.1).

```bash
git clone https://github.com/quiqueck/wunderreich.git
cd wunderreich
./gradlew build
```

The mod jar is written to `build/libs`. Each Minecraft version has its own release branch: `release/26.3`, `release/26.2`, `release/26.1`, `release/1.21.6` and `release/1.20` (1.20.1).

## AI Usage

The ideas and the design of Wunderreich are human-made: we come up with the concepts, guide every design decision and implement the code. We use agentic AI as a tool for the following tasks:

- tooling and automation,
- code review,
- proofreading and writing documentation (code comments and this README),
- boilerplate work, including migrating the codebase to new Minecraft versions,
- many of our automated tests.

Everything the AI generates is reviewed and, where needed, edited by us before it is released. We also playtest every release ourselves.
